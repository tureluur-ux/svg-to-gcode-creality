# svg-to-gcode-creality
SVG to G-code converter tailored for Creality 3D printers.
I was searching for a good svg 2 gcode software but i didn't so i created one by myself. :)

Tools in this Converter;
- svg to gcode
- line mode
- color in mode
- choose your model in the list of creality printers
- adjust marge
- Download .gcode and plot ;)
